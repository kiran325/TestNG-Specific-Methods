# TestNG Specific Methods Execution with Selenium

This project demonstrates how to control and execute specific test methods using **TestNG** with **Selenium WebDriver** in a Maven-based Java framework. It highlights practical usage of TestNG annotations such as `@Test`, `dependsOnMethods`, and XML-based method inclusion via `testng.xml`.

## 📌 Features

- ✅ Execute selected test methods via `testng.xml`
- ✅ Use of `@Test` annotations with priorities and dependencies
- ✅ Integration with Selenium to automate Google Search
- ✅ Browser automation using ChromeDriver
- ✅ Structured Maven project with `pom.xml` dependencies

## 🧪 Technologies Used

- Java
- TestNG
- Selenium WebDriver
- Maven
- ChromeDriver
